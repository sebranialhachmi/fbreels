# Comment enregistrer un Reel Facebook sur iPhone (et où le retrouver)

Sur iPhone, enregistrer une vidéo semble plus compliqué que sur Android ou sur ordinateur, surtout parce que le fichier n'atterrit pas tout de suite dans votre pellicule. Bonne nouvelle : une fois que l'on sait où iOS range les choses, le parcours est tout à fait prévisible. Voici le chemin complet pour un Reel **public** que vous avez le droit de conserver : copier le lien, le vérifier, télécharger le fichier, le retrouver, puis le déplacer dans Photos si vous le souhaitez.

## D'abord, une mise au point

Tous les Reels ne peuvent pas être enregistrés. Un Reel ne peut être traité que s'il est public, toujours disponible, et si un fichier téléchargeable existe réellement pour lui. Les vidéos privées, réservées aux amis ou publiées dans des groupes privés sont hors de portée, et aucun outil sérieux ne devrait vous demander votre mot de passe Facebook pour contourner cela. N'oubliez pas non plus que la vidéo a été créée par quelqu'un d'autre : ne la conservez que si elle est à vous, si vous avez une autorisation, ou si la loi permet clairement votre usage. L'article sur le [droit d'auteur et l'usage responsable](blog:copyright-privacy-responsible-use) en explique les bases.

## Étape 1 : copier le lien du Reel dans l'application Facebook

1. Ouvrez l'application Facebook et trouvez le Reel.
2. Touchez la flèche **Partager**, généralement sur le côté droit, sous les boutons J'aime et Commenter.
3. Dans la feuille de partage, choisissez **Copier le lien**.

Le libellé des menus varie selon les versions de l'application, mais une option « Copier le lien » est presque toujours présente. Si vous avez ouvert le Reel dans un navigateur, copiez l'adresse complète dans la barre d'adresse.

Astuce : si vous avez choisi une application comme Messages dans la feuille de partage, vous obtiendrez souvent un lien court de partage (par exemple contenant `/share/r/`). Pas de souci : le téléchargeur les accepte aussi.

## Étape 2 : ouvrir le téléchargeur dans Safari

Utilisez **Safari** pour cette opération. Sur iPhone et iPad, Safari intègre un gestionnaire de téléchargements (depuis iOS 13) et enregistre les fichiers à un endroit où vous pouvez les retrouver. D'autres navigateurs peuvent se comporter différemment selon leur version.

Rendez-vous sur la [page d'accueil de __BRAND__](page:home), touchez le champ, puis maintenez le doigt appuyé et choisissez **Coller**. Vous pouvez aussi toucher le bouton presse-papiers ; Safari peut vous demander d'autoriser le collage, et dans ce cas vous pouvez toucher **Autoriser le collage**. Coller seul n'envoie rien à notre serveur.

## Étape 3 : appuyer sur Télécharger et lire le résultat

Touchez **Télécharger**. La page vérifie le lien et affiche ce qui est disponible. Vous pouvez voir un titre et une ou plusieurs options, comme une vidéo SD ou HD. Seules les options qui existent réellement sont affichées. Si vous voyez à la place un message comme « privé ou inaccessible » ou « aucun format téléchargeable », l'article de dépannage [pourquoi le téléchargement d'un Reel Facebook peut échouer](blog:why-download-fails) explique chaque cas.

## Étape 4 : enregistrer le fichier

Touchez **Enregistrer** à côté de l'option voulue. Safari affiche une invite demandant s'il faut télécharger le fichier. Touchez **Télécharger**. Une petite icône de téléchargement (une flèche dans un cercle) apparaît dans la barre d'outils de Safari pendant l'arrivée du fichier.

Les liens de téléchargement expirent au bout de peu de temps, environ 15 minutes. Si vous avez attendu trop longtemps, appuyez simplement de nouveau sur Télécharger pour la vidéo afin d'obtenir un lien neuf.

## Étape 5 : retrouver le fichier

Touchez l'icône de téléchargement dans Safari : le fichier apparaît dans une liste. Touchez la loupe à côté pour l'afficher dans l'application **Fichiers**. Sinon, ouvrez **Fichiers → Parcourir → Téléchargements**. Selon vos réglages, le dossier Téléchargements se trouve sur votre iPhone ou dans iCloud Drive.

## Étape 6 (facultative) : l'ajouter à Photos

Les vidéos de l'application Fichiers ne sont pas dans votre pellicule tant que vous ne les y ajoutez pas :

1. Dans Fichiers, touchez la vidéo pour l'afficher.
2. Touchez le bouton **Partager** (carré avec une flèche).
3. Choisissez **Enregistrer la vidéo**.

La vidéo apparaît alors dans Photos. Si vous ne voyez pas **Enregistrer la vidéo**, c'est probablement que le format du fichier n'est pas lisible par Photos (certains formats web, comme WebM, ne sont pas pris en charge). Dans ce cas, gardez le fichier dans Fichiers et lisez-le depuis là, ou cherchez une autre option de qualité en revérifiant le lien.

## Problèmes fréquents sur iPhone et solutions

**Rien ne se passe quand je touche Enregistrer.** Vérifiez que les réglages de Safari (Réglages → Safari) ne bloquent pas les fenêtres ou téléchargements. Assurez-vous d'avoir assez d'espace de stockage. Réessayez après avoir rechargé la page.

**Le fichier ne se lit pas.** Certains formats ne sont pas pris en charge par Photos. Essayez l'autre option de qualité si elle est proposée, ou ouvrez le fichier avec une application de lecture comme VLC.

**Le lien ne se colle pas.** Maintenez le doigt dans le champ pour coller manuellement. Si vous voyez « lien invalide », copiez de nouveau le lien complet avec **Partager → Copier le lien**.

**Je ne trouve pas le fichier.** Dans Safari, touchez l'icône de téléchargement puis la loupe, ou cherchez le nom du fichier dans l'application Fichiers.

**On me dit que la vidéo est privée.** Alors elle ne peut pas être traitée. Ouvrez le Reel dans une fenêtre de navigation privée, sans être connecté ; si vous ne pouvez pas le voir, il n'est pas public.

## Les alternatives intégrées à Facebook

Facebook propose sa propre fonction **Enregistrer**, qui place un Reel ou une vidéo dans vos éléments enregistrés au sein de Facebook. Cela ne met pas de fichier sur votre téléphone, mais c'est le moyen le plus simple de retrouver une vidéo plus tard. Si vous êtes le créateur, vous pouvez en général obtenir une copie originale de vos propres vidéos depuis votre compte ou les outils de votre Page (par exemple Meta Business Suite ou l'option « Télécharger vos informations » des paramètres du compte) ; les noms exacts des menus changent avec le temps.

En dernier recours, pour un contenu que vous avez le droit de conserver, l'**enregistrement d'écran** intégré à l'iPhone peut capturer une vidéo en cours de lecture. La qualité est généralement inférieure à celle du fichier d'origine et l'enregistrement inclut tout ce qui s'affiche à l'écran ; mieux vaut donc utiliser un original ou un vrai téléchargement quand c'est possible.

## Petit aide-mémoire

1. Copiez le lien avec **Partager → Copier le lien**.
2. Ouvrez le téléchargeur dans Safari et collez le lien.
3. Appuyez sur **Télécharger** et examinez les options réelles.
4. Touchez **Enregistrer**, puis **Télécharger** dans l'invite de Safari.
5. Retrouvez le fichier dans **Fichiers → Téléchargements**.
6. Utilisez **Partager → Enregistrer la vidéo** pour l'ajouter à Photos.
